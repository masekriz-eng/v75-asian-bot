Asian Directional Bot — Technical + Rolling WR + Streak Persistence

Validation build. Current Deriv public market-data WebSocket + authenticated Demo trading stream. One ASIANU/ASIAND trade at a time. Core direction requires Price vs previous-5 SMA + SMA slope + Momentum 3 to agree 3/3. Distance is a configurable entry filter. Volatility is contextual only. Rolling win rate is advisory in BALANCED mode. Winning-streak persistence affects sizing only. Loss progression and loss-streak protection are separate risk controls.

Market & entry settings

Core confirmation is configurable: 3/3 STRICT, 2/3 BALANCED, or 2/3 + WR TIE-BREAK. In the tie-break mode, a 3/3 signal trades normally; a 2/3 signal must also agree with a qualifying rolling WR direction. Momentum 5 and acceleration are recorded; Momentum 5 becomes a hard confirmation only after 3 consecutive losses when protection is enabled.

Rolling win rate & streak persistence
Persistence is direction-specific: UP→UP→UP is an UP streak; DOWN→DOWN→DOWN is a DOWN streak. Changing direction resets the current winning streak for sizing. The persistence statistic is P(next win | N prior same-direction wins).
Loss progression — adjustable

Next-trade stake after L consecutive losses = min(base × factor^min(L,max level), cap). Set the factor to 1.00 for flat staking. A win resets the loss progression to base.

Loss-streak protection

Connection resilience: both WebSockets send a keepalive ping every 25 seconds. If the idle Demo trading socket drops, the bot automatically reconnects up to 3 times before stopping. If a contract is active when the trading socket drops, the bot stops safely and never opens a replacement trade.

The base entry rule follows the selected core confirmation mode + selected distance threshold. After 3 losses, Momentum 5 must also agree. At 4 losses, trading pauses until 5 distinct valid signal events have appeared. At 5 losses, the session stops.

Optional warm-start history

Imported records are used only for rolling WR and persistence calculations. They are stored by market. Historical records from a different strategy are not proof of current behavior.

Demo safety: the bot requires a DOT demo Options account. The PAT is used only in the current page memory and is never written to localStorage. Market data is read from a separate public WebSocket; trading remains on the authenticated Demo WebSocket. If either connection drops, the bot stops rather than opening another trade.
Decision flow: core confirmation → distance threshold → core-mode / WR checks → loss-streak protection → one directional trade. In 2/3 + WR TIE-BREAK mode, 2/3 signals require a qualifying WR match; 3/3 signals do not. Persistence never changes direction; it only changes stake when the current same-direction winning streak qualifies.
