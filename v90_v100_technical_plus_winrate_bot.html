Deriv Asian Direction Bot — Technical Features + Rolling Win Rate

Combined single-direction research/trading build for Volatility 90 / Volatility 100 and other markets that expose both ASIANU and ASIAND. The engine first requires the three mandatory market conditions to align with a direction, then uses selected confirmation features, and finally requires the rolling historical win-rate model to confirm the same direction.

1. Demo connection
The page sends the PAT directly to Deriv only to request a short-lived authenticated WebSocket URL. It is not stored in localStorage.
2. Market
Default market: V75 (1s). Discovering markets is optional; the selected market will be fully revalidated before trading.
Data integrity: waiting for selected-market history.
3. Combined direction engine
Decision flow: (1) mandatory technical direction = price vs previous-5 SMA + SMA slope; (2) mandatory volatility = stdev(20) at or above this market's recent rolling baseline; (3) optional confirmations; (4) the rolling win-rate model must select the same direction with the required gap. Only one contract is purchased.
4. Technical feature controls
Mandatory: price/SMA direction, SMA slope direction, and market-relative volatility. Optional: momentum 3, normalized distance, momentum 5, and acceleration. The previous-pair feature is not used as a direction vote because this bot places one directional contract rather than paired DOWN + UP trades; the previous single-trade result is still recorded for research.
5. Money management
When ON, consecutive losses move the next stake through $0.35 → $0.40 → $0.46 → $0.53 → $0.61 → $0.70. Any win resets to $0.35. This is a capped progression, not a guarantee of recovery.
6. Seed / persist directional history
V90/V100 bundled Demo research history can bootstrap the rolling win-rate engine automatically; other markets require imported history or fresh observations.
