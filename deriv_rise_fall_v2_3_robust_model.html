Entry logic: SMA(5) slope + Momentum 3/5 + normalized distance + acceleration + volatility → KNN P(RISE)/P(FALL) → walk-forward calibration → choose higher-probability side → request a live Deriv proposal → calculate actual profit-on-stake payout → enter only when probability and payout both pass their thresholds. After a loss, the next model-approved trade can increase stake according to the selected martingale mode; a win resets to base. The model still chooses direction independently—no forced opposite trade.

V2.2 model: 9 scale-normalized features (SMA distance/slope, M1/M3/M5, acceleration, volatility ratios, persistence, shock). KNN uses standardized feature distance + recency weighting. Walk-forward calibration uses an outcome embargo so labels whose expiry is not yet reached cannot enter a historical prediction. Entries also require reasonable neighbor agreement and distance.
